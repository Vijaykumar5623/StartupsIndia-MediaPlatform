# Configuration

Everything needed to configure, build, and run the app. Values that are secret
or machine-specific are **not** in the repo — see [../SECURITY.md](../SECURITY.md).

---

## 1. Build-time configuration (`--dart-define`)

The app has no runtime `.env` file. Configurable values are compiled in via
`--dart-define` and read in [../lib/core/config/app_config.dart](../lib/core/config/app_config.dart).
Reference placeholders are in [../.env.example](../.env.example).

| Key | Default | Meaning |
|---|---|---|
| `ENV` | `prod` | App environment (`development` locally; CI passes `prod`). |
| `CLOUDINARY_CLOUD_NAME` | `dmrp1d1tv` | Cloudinary cloud name (client-side, not secret). |
| `CLOUDINARY_UPLOAD_PRESET` | `startups india upload preset` | Unsigned upload preset — **must be restricted in the Cloudinary console** before launch. |

Example:

```bash
flutter build appbundle --release --dart-define=ENV=prod
```

## 2. Firebase

- Project ID: `startupsindia-mediaplatform` (see [../firebase.json](../firebase.json)).
- Dart config: [../lib/firebase_options.dart](../lib/firebase_options.dart)
  (generated by `flutterfire configure`). API keys here are **public client
  identifiers**, protected by App Check + Firestore rules — not secrets.
- Android config: `android/app/google-services.json` — **gitignored**; provided
  locally and injected in CI via the `GOOGLE_SERVICES_JSON` secret.
- Services used: Auth, Cloud Firestore (offline persistence on), Cloud Messaging,
  App Check (Play Integrity in release, debug provider in debug), Crashlytics.
- Firestore rules/indexes: [../firestore.rules](../firestore.rules),
  [../firestore.indexes.json](../firestore.indexes.json). Deploy with
  `firebase deploy --only firestore:rules`.

## 4. App icon & launch assets

- Launcher icon source: `assets/startupsindia/Icon.png`, generated via
  `flutter_launcher_icons` (config at the bottom of [../pubspec.yaml](../pubspec.yaml)).
  Regenerate with `dart run flutter_launcher_icons`.
- Splash/launch backgrounds live under `android/app/src/main/res/`.

---

## 5. Assets

Declared in [../pubspec.yaml](../pubspec.yaml) `flutter.assets`:

- `assets/icons/` — SVG UI icons (Google, Facebook, mail, message).
- `assets/images/` — onboarding, thumbnails, hero images.
- `assets/flags/` — country flags (onboarding country picker).
- `assets/startupsindia/` — brand logos and app icon.

Fonts use `google_fonts` (Poppins) fetched at runtime; no bundled font files.

## 6. Permissions (Android)

Declared in `android/app/src/main/AndroidManifest.xml`. Notably includes
`POST_NOTIFICATIONS` (Android 13+) for FCM. Review the full permission list
against the Play Data Safety form before launch — see
[play-store-launch-checklist.md](play-store-launch-checklist.md).

## 7. Signing

Release signing is driven by `android/key.properties` (gitignored). If it is
absent, release builds fall back to the debug key. See
[release-plan.md](release-plan.md) for keystore creation and the CI signing flow.

`key.properties` shape (values are placeholders — never commit real ones):

```properties
storeFile=app/release.jks
storePassword=<from secret / password manager>
keyAlias=<alias>
keyPassword=<from secret / password manager>
```

## 8. CI configuration (GitHub Actions)

Two workflows in [../.github/workflows/](../.github/workflows/):

- `android_build.yml` — on push/PR: builds a signed ARM64 release APK artifact.
- `android_firebase_release.yml` — manual (`workflow_dispatch`): builds APK + AAB,
  distributes the APK to Firebase App Distribution, and publishes a prerelease.

Required GitHub Actions **secrets**:

| Secret | Purpose |
|---|---|
| `GOOGLE_SERVICES_JSON` | Base64 of `google-services.json` |
| `KEYSTORE_BASE64` | Base64 of the release keystore |
| `KEYSTORE_PASSWORD` / `KEYSTORE_KEY_ALIAS` / `KEYSTORE_KEY_PASSWORD` | Signing credentials |
| `FIREBASE_SERVICE_ACCOUNT_JSON` | Admin SDK key for App Distribution |
| `FIREBASE_ANDROID_APP_ID` | Firebase Android app id |
| `FIREBASE_TESTERS` | Tester emails for App Distribution |

See [../SECURITY.md](../SECURITY.md) for handling rules.
